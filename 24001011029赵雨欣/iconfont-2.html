方式二 · 直接内联 SVG 
<!-- 直接复制 SVG 代码到页面，无需 JS -->
<svg xmlns="http://www.w3.org/2000/svg"
     viewBox="0 0 24 24"
     fill="none"
     stroke="currentColor"
     stroke-width="2"
     stroke-linecap="round"
     stroke-linejoin="round">
  <path d="..." />
</svg>

/* 颜色由 CSS color 控制：*/
svg { color: #2dd4bf; }
